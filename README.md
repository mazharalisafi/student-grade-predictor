# Student Grade Predictor

A beginner ML project that predicts student final grades based on study hours and attendance using Linear Regression in Python.

## Technologies Used
- Python
- scikit-learn
- pandas
- matplotlib

## How to Run
1. Install libraries: pip install scikit-learn pandas matplotlib
2. Run: python grade_predictor.py
3. Enter study hours and attendance when asked
